# Optimized Algorithms Project

## Project Overview

This project demonstrates the optimization and debugging of algorithms using C# and the .NET platform. It focuses on improving performance, data structures, task scheduling, sorting and reliable task execution.

## Project Components

### 1. Binary Tree
An optimized AVL Tree that uses balancing techniques to improve data retrieval and insertion.

### 2. Task Scheduling
A priority queue implemented using a binary min-heap to manage tasks according to priority.

### 3. Sorting Algorithm
An optimized Merge Sort implementation that improves sorting from O(n²) to O(n log n).

### 4. Task Execution
A task execution implementation using exception handling and logging to improve reliability.

### 5. Performance Report
A report comparing the original and optimized algorithms, including their theoretical time complexities.
